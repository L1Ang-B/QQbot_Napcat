# 🤖 我的第一个 QQ 机器人

这是一个作为“个人成长记录”的项目,在 Trae 的帮助下，基于 NcatBot 和 NapCat 搭建 QQ 机器人，并接入免费大模型，实现群聊名词自动解析

最初我只是想给群友提供一个便捷的工具：当聊天中出现医学名词、游戏黑话时，机器人能自动回复通俗的解释

最初我的选择是Deepseek Harness（DSH），但我感觉目前还不够成熟，频繁的更新很影响插件的生态，如果去研究agent框架本身，DSH作为一个开源项目应该会很不错（如果未来有一天我强大到去研究自己的AI智能体，我或许会回去）

后面我把框架的焦点挪走了，Trae相对成熟，而且个人版免费，是不二之选（这个时候很感慨没钱），借助Trae的IDE，我准备好了Ncatbot。

在完成QQ账号层面的客观准备后，我们去选择另一个关键————Napcat。Napcat似乎是开源的社区项目，本土化和UI做的都非常不错，可惜我用不上那么多功能。

在Napcat上完成bot的创建（链接方式选择的是正向链接WS）。Napcat上的最大难点就是QQ的版本匹配问题，这个在如今的互联网上不算难题，靶向版本在公开软件园是能找到的。

完成一切后就是接入大模型的选择，由于本身是实验性项目，选择是智谱的flash免费AI。

本身没什么难的，WebSocket依靠Napcat的强大基本不会出问题。再者也是让自己慢慢熟悉Github，说是接轨可能也有点晚了吧。

差不多就这些，今天是26年的秋天，早上晴转阴。
